TimeFlow gives you a clear, at-a-glance picture of where you are in time. Instead of abstract dates and numbers, you see visual progress bars showing how much of each time period has elapsed — and how much remains.

<Note>
  TimeFlow requires **Android 8.1 Oreo (API level 27)** or higher (targetSdk 36). Check your Android version in **Settings → About phone → Android version** before installing.
</Note>

## What TimeFlow does

Time passes whether you track it or not. TimeFlow makes the flow of time tangible by turning each time unit into a living progress bar. You can see that today is 62% complete, the week is nearly done, or that you're already three quarters through the year — all in one view.

Beyond the life bars, TimeFlow layers in a calendar, task management, and event tracking so you can act on what you see, not just observe it.

## Technical stack

TimeFlow is built entirely with modern Android development tools:

| Technology | Purpose |
|---|---|
| **Kotlin** | Primary language |
| **Jetpack Compose** | Declarative UI framework |
| **Material 3** | Design system and theming |
| **Glance** | Home screen widget rendering |
| **Room** | Local database for tasks and events |
| **Hilt** | Dependency injection |
| **AlarmManager** | Scheduling task and event reminders |
| **DataStore** | Persisting app preferences and onboarding state |
