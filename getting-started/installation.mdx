TimeFlow is distributed as an APK file through GitHub Releases. It is not available on the Google Play Store, so you need to allow installation from unknown sources before you can install it.

<Warning>
  Enabling **Install unknown apps** allows your device to install applications from outside the Play Store. Only enable this for sources you trust. You can disable it again after installing TimeFlow.
</Warning>

## System requirements

- Android 8.1 Oreo (API 27) or higher
- Sufficient storage for the APK and app data

## Install TimeFlow

<Steps>
  <Step title="Allow installation from unknown sources">
    Before downloading, grant your browser or file manager permission to install apps.

    <Tabs>
      <Tab title="Android 8.1–9">
        1. Open **Settings → Apps & notifications**.
        2. Tap **Advanced → Special app access**.
        3. Tap **Install unknown apps**.
        4. Select your browser (e.g., Chrome) and toggle **Allow from this source** on.
      </Tab>
      <Tab title="Android 10+">
        1. Open **Settings → Apps**.
        2. Tap the three-dot menu and select **Special app access**.
        3. Tap **Install unknown apps**.
        4. Select your browser or file manager and toggle **Allow from this source** on.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Download the APK">
    Go to the TimeFlow releases page on GitHub:

    ```
    https://github.com/dev778g-me/TimeFlow/releases
    ```

    Find the latest release — currently **v1.2.1** (versionCode 5). Under **Assets**, tap the `.apk` file to download it to your device.

    <Note>
      Always download from the official GitHub Releases page. Avoid third-party APK sites.
    </Note>
  </Step>

  <Step title="Install the APK">
    Once the download completes:

    1. Open your notifications drawer and tap the downloaded APK, **or** open your file manager and navigate to your **Downloads** folder and tap the file.
    2. Tap **Install** on the confirmation screen.
    3. Wait for installation to finish, then tap **Open** or **Done**.
  </Step>

  <Step title="Grant notification permission">
    On first launch, TimeFlow asks for permission to send notifications. Tap **Allow** to enable reminders for your tasks and events.

    <Tip>
      Notification permission is required for task and event reminders to work. If you deny it during onboarding, you can grant it later in **Settings → Apps → TimeFlow → Permissions → Notifications**.
    </Tip>
  </Step>

  <Step title="Add the home screen widget (optional)">
    To place a TimeFlow widget on your home screen:

    1. Long-press an empty area of your home screen.
    2. Tap **Widgets**.
    3. Search for **TimeFlow** in the widget picker.
    4. Long-press the widget and drag it to your desired home screen position.
    5. Release to place it.

    The widget updates automatically to reflect the current day, week, month, and year progress.
  </Step>
</Steps>

## Verify the installation

After installing, open TimeFlow and complete the short onboarding flow. You should land on the main timer screen showing today's progress bars. If the app does not open or crashes, confirm your Android version meets the API 27 minimum requirement.
