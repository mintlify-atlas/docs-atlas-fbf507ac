## What is TimeFlow?

TimeFlow is a **Material 3** Android application that helps you stay aware of time passing. It shows your progress through the current day, week, month, and year using animated progress bars — giving you a clear, honest view of where you are in time so you can stay intentional and productive.

Beyond the progress bars, TimeFlow gives you a full task and event manager with a beautiful calendar view, smart notifications that fire exactly when you need them, and home screen widgets so your time awareness is always just a glance away.

## Built with

TimeFlow is a native Android app built on the modern Android stack:

- **Kotlin** — the primary language
- **Jetpack Compose + Material 3** — declarative UI with expressive theming
- **Jetpack Glance** — composable home screen widgets
- **Room** — local database for tasks and events
- **Hilt** — dependency injection
- **AlarmManager** — precise alarm-based notifications
- **Jetpack Navigation Compose** — type-safe screen navigation
